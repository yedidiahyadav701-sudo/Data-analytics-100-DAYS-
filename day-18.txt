SQL Practice Exercise: School Management
System
 
 
1.   Context & Schema
 
We are modeling a school database to track student performance.
•            Students: Stores student personal details.
•            Subjects: Stores the list of subjects (Mathematics, Science, Hindi, etc.).
•            Exams: Stores details about specific exam events (e.g., Half-Yearly 2024).
•            Marks: The transaction table linking students, subjects, and exams with a score.

Run this script to initialize the tables and populate them with the new data.
 
 
 Create database studentdb;

2.   Practice Questions
 
 
 
Level 1: Simple (Basic Selection & Filtering)
 
 
1.         Retrieve all students: List the first name and last name of every student.
 
2.         Filter by Score: Find all entries in the Marks table where the score is greater than 80.
3.         Sort Data: List all exams sorted by their date, starting with the most recent.
 
 
Level 2: Intermediate (Joins & Aggregation)
 
 
4.         Student Marks: List the First Name, Subject Name, and Score for every mark recorded.

5.         Subject Averages: Calculate the average score for each subject. Display the Subject Name and the Average Score.
6.         Count Exams: How many marks have been recorded specifically for "Aarav Sharma"?
 
 
Level 3: Complex (Subqueries, Grouping & Logic)
 
 
7.         Top Performer: Find the student (First Name, Last Name) who has the highest single score in any exam.
8.         Scores by Exam: Display the Exam Name and the total sum of scores for that exam, but only for exams where the total sum is greater than 250.
9.         Pass/Fail Label: Create a report showing the Student Name, Subject, Score, and a status column that says "Pass" if the score is 70 or above, and "Fail" if below.
 
 
 
3.  Answers
 
 
 
Answers: Level 1
 
 
1.  Retrieve all students
SQL
 
SELECT first_name, last_name FROM Students;
2.  Filter by Score
SQL
 
SELECT * FROM Marks WHERE score > 80;
3.  Sort Data
SQL
 
SELECT * FROM Exams ORDER BY exam_date DESC;

Answers: Level 2
 
 
4.  Student Marks (Inner Join)
SQL
 
SELECT St.first_name, Sb.subject_name, M.score FROM Marks M
JOIN Students St ON M.student_id = St.student_id JOIN Subjects Sb ON M.subject_id = Sb.subject_id;
5.  Subject Averages (Aggregation)
SQL
 
SELECT Sb.subject_name, AVG(M.score) as average_score FROM Marks M
JOIN Subjects Sb ON M.subject_id = Sb.subject_id GROUP BY Sb.subject_name;
6.  Count Exams (Filtering & Aggregation)
SQL
 
SELECT COUNT(*) as total_exams_taken FROM Marks M
JOIN Students St ON M.student_id = St.student_id
WHERE St.first_name = 'Aarav' AND St.last_name = 'Sharma';
 
Answers: Level 3
 
 
7.  Top Performer (Subquery)
SQL
 
SELECT first_name, last_name FROM Students
WHERE student_id = ( SELECT student_id FROM Marks
ORDER BY score DESC LIMIT 1
);

-- Note: Use 'TOP 1' instead of 'LIMIT 1' if you are using MS SQL Server.
8.  Scores by Exam (Having Clause)
SQL
 
SELECT E.exam_name, SUM(M.score) as total_score FROM Marks M
JOIN Exams E ON M.exam_id = E.exam_id GROUP BY E.exam_name
HAVING SUM(M.score) > 250;
9.  Pass/Fail Label (CASE Statement)
SQL
 
SELECT
St.first_name, Sb.subject_name, M.score,
CASE
WHEN M.score >= 70 THEN 'Pass' ELSE 'Fail'
END as status FROM Marks M
JOIN Students St ON M.student_id = St.student_id JOIN Subjects Sb ON M.subject_id = Sb.subject_id;




MySQL Practice Lab: Jeevan Raksha
Pharmacy
 
 
1.   Case Study Overview
Store Name: Jeevan Raksha Pharmacy
Location: India
Business Logic:
•            Customers: Local residents purchasing medicines.
•            Suppliers: Distributors providing stock to the pharmacy.
•            Medicines: The inventory (Tablets, Syrups, etc.) with expiry dates.
•            Bills (Orders): The transaction record containing total amount and payment mode (UPI, Cash, Card).
•            Order Items: The breakdown of which medicines are included in a specific bill.
 
2.   Entity Relationship Diagram (ERD)
 









 
3.   Database Setup Script
 
Copy and execute the following SQL script in your MySQL Workbench/Terminal to create the environment for the exercise.
 
 
CREATE DATABASE IF NOT EXISTS jeevan_raksha_pharmacy; 
USE jeevan_raksha_pharmacy;
-- 1. Create Tables CREATE TABLE customers (
customer_id INT AUTO_INCREMENT PRIMARY KEY,
name VARCHAR(100), phone VARCHAR(15), city VARCHAR(50)
);
 
CREATE TABLE suppliers (
supplier_id INT AUTO_INCREMENT PRIMARY KEY, supplier_name VARCHAR(100),
contact_person VARCHAR(100), phone VARCHAR(15)
);
 
CREATE TABLE medicines (
medicine_id INT AUTO_INCREMENT PRIMARY KEY, name VARCHAR(100),
category VARCHAR(50), price DECIMAL(10,2),
stock_quantity INT, expiry_date DATE, supplier_id INT,
FOREIGN KEY (supplier_id) REFERENCES suppliers(supplier_id)
);
 
CREATE TABLE orders (
order_id INT AUTO_INCREMENT PRIMARY KEY,

customer_id INT, order_date DATE,
total_amount DECIMAL(10,2),
payment_mode ENUM('UPI', 'Cash', 'Card'),
FOREIGN KEY (customer_id) REFERENCES customers(customer_id)
);
 
CREATE TABLE order_items (
item_id INT AUTO_INCREMENT PRIMARY KEY,
order_id INT, medicine_id INT, quantity INT,
subtotal DECIMAL(10,2),
FOREIGN KEY (order_id) REFERENCES orders(order_id),
FOREIGN KEY (medicine_id) REFERENCES medicines(medicine_id)
);

4.   Exercise Questions
 
 
 
Level 1: Simple Queries
 
 
1.         Customer List: Retrieve the name and city of all customers.
2.         Stock Check: Find the names of medicines that are 'Syrup' or 'Injection'.
 
3.         High Value Bills: List all orders where the total_amount is greater than ₹500.
4.         Mumbai Residents: Find the phone numbers of all customers living in 'Mumbai'.
 
 
Level 2: Intermediate Queries (Aggregates & Joins)
 
 
5.         Payment Analysis: How many orders were paid using 'UPI'?

6.         Supplier Count: Count how many medicines are supplied by 'Apollo Distributors' (Use Subquery or Join).
7.         Order Details: List the Customer Name, Order Date, and Total Amount for every order placed.
8.         Revenue by Mode: Calculate the total money earned through each payment mode (UPI, Card, Cash).
 
 
Level 3: Complex Queries
 
 
9.         Best Selling Medicine: Which medicine has been sold the most (in terms of total quantity)?
 
10.  	Customer Lifetime Value: List the names of customers who have spent more than ₹1000 in total across all their orders.
11.  	Inventory Audit: List the medicine_name, stock_quantity, and
supplier_name for medicines that have less than 50 units left in stock.
 
 
 
5.  Answer Key
 
1.  Customer List
 
SELECT name, city FROM customers;
 
2.  Stock Check (Syrup/Injection)
 
SELECT name, category FROM medicines WHERE category IN ('Syrup', 'Injection');
 
3.  High Value Bills
 
SELECT * FROM orders WHERE total_amount > 500;
 
4.  Mumbai Residents
 
SELECT phone FROM customers WHERE city = 'Mumbai';
 
5.  Payment Analysis (UPI Count)

SELECT COUNT(*) FROM orders WHERE payment_mode = 'UPI';
 
6.  Supplier Count (Apollo)
 
SELECT COUNT(*) FROM medicines m
JOIN suppliers s ON m.supplier_id = s.supplier_id WHERE s.supplier_name = 'Apollo Distributors';
 
7.  Order Details (Join)
 
SELECT c.name, o.order_date, o.total_amount FROM customers c
JOIN orders o ON c.customer_id = o.customer_id;
 
8.  Revenue by Mode
 
SELECT payment_mode, SUM(total_amount) as Total_Revenue FROM orders
GROUP BY payment_mode;
 
9.  Best Selling Medicine
 
SELECT m.name, SUM(oi.quantity) as total_sold FROM order_items oi
JOIN medicines m ON oi.medicine_id = m.medicine_id GROUP BY m.name
ORDER BY total_sold DESC LIMIT 1;
 
10.  Customer Lifetime Value (>1000)
 
SELECT c.name, SUM(o.total_amount) as total_spent FROM customers c
JOIN orders o ON c.customer_id = o.customer_id GROUP BY c.customer_id, c.name
HAVING total_spent > 1000;
 
11.  Inventory Audit (Low Stock & Supplier)
 
SELECT m.name, m.stock_quantity, s.supplier_name FROM medicines m
JOIN suppliers s ON m.supplier_id = s.supplier_id WHERE m.stock_quantity < 50;
