Clauses in MYSQL
-------------------------------
In MySQL, clauses are used to control how data is selected, filtered, grouped, sorted, or modified in SQL queries.
 They make SQL statements more meaningful and powerful.
Think of clauses like instructions given to the database.

where clause
================
filter records based on specified conditions where clauses can be used as comparison operators, logical operators and ..etc operators.

syntax
---------
select column1,column2....
from table
where condition.

Group by clause
===================
The group by clause is used to group rows having the same values in one or more columns. It is commonly used with aggregate functions such as sum(),min(),max(),avg(),count().

syntax
---------
select column-name,aggregate_function(column-name)
from table-name
group by column_name.

Having Clause
---------------
The having clause is used to filter grouped records after group by clause. it is similar to where but it works on grouped instead of individual rows.

syntax
-----------
select column-name,
aggregate_function(column-name)
from table-name
group by column-name
having condition.

Order By Clause
------------------
the order by clause is used to sort the result set in ascending(ASC)or descending(Desc)order.
asc-->Ascending order by default.
Desc-->Descending order

syntax:
----------
select column-name
from table-name
order by column-name asc;

-- Create the Student table
CREATE TABLE Student (
	student_id INT AUTO_INCREMENT PRIMARY KEY,
    first_name VARCHAR(50),
	last_name VARCHAR(50),
	email VARCHAR(100),
	grade DECIMAL(5, 2),
	enrollment_date DATE,
	phone_number VARCHAR(15)
);
 
-- Insert sample data
INSERT INTO Student (first_name, last_name, email, grade, enrollment_date, phone_number) VALUES
('John', 'Doe', 'john.doe@example.com', 88.50, '2024-01-10', '555-0101'),
('Jane', 'Smith', 'jane.smith@example.com', 92.00, '2024-01-15', '555-0102'),
('Emily', 'Johnson', 'emily.johnson@example.com', 78.00, '2024-02-01', NULL),
('Michael', 'Williams', 'michael.williams@example.com', 85.00, '2024-01-20', '555-0103'),
('Anna', 'Brown', 'anna.brown@example.com', 95.00, '2024-02-05', '555-0104');

-- Perform WHERE clause operations
-- 1. Basic Filtering by Grade
SELECT * FROM Student WHERE grade > 85;
 
-- 2. Filtering by Enrollment Date
SELECT * FROM Student WHERE enrollment_date >= '2024-01-15';
 
-- 3. Filtering by Email Domain
SELECT * FROM Student WHERE email LIKE '%example.com';
 
-- 4. Filtering by NULL Values in Phone Number
SELECT * FROM Student WHERE phone_number IS NULL;
 
-- 5. Filtering with Multiple Conditions
SELECT * FROM Student WHERE grade < 90 AND enrollment_date < '2024-02-01';
 
-- Perform GROUP BY operations
-- 1. Group by Enrollment Date
SELECT enrollment_date, COUNT(*) AS student_count FROM Student GROUP BY enrollment_date;
 
 
-- 3. Group by Enrollment Month
SELECT MONTH(enrollment_date) AS month, COUNT(*) AS student_count FROM Student GROUP BY MONTH(enrollment_date);
 
-- 4. Group by Grade and Enrollment Date
SELECT grade, enrollment_date, COUNT(*) AS student_count
FROM Student
GROUP BY grade, enrollment_date;
 
-- 5. Group by Email Domain
SELECT SUBSTRING_INDEX(email, '@', -1) AS email_domain, COUNT(*) AS student_count
FROM Student
GROUP BY email_domain;
 
-- Perform HAVING operations
-- 1. Filtering Groups with Student Count Greater Than 1
SELECT enrollment_date, COUNT(*) AS student_count
FROM Student
GROUP BY enrollment_date
HAVING COUNT(*) > 1;
 
-- 2. Filtering by Average Grade
SELECT enrollment_date, AVG(grade) AS average_grade
FROM Student
GROUP BY enrollment_date
HAVING AVG(grade) > 85;
 
-- 3. Filtering by Total Grade
SELECT enrollment_date, SUM(grade) AS total_grade
FROM Student
GROUP BY enrollment_date
HAVING SUM(grade) > 400;
 
-- Perform ORDER BY operations
-- 1. Basic Sorting by Grade
SELECT * FROM Student ORDER BY grade;
 
-- 2. Descending Order by Grade
SELECT * FROM Student ORDER BY grade DESC;
 
-- 3. Sorting by Enrollment Date and Grade
SELECT * FROM Student ORDER BY enrollment_date, grade DESC;
 
-- 4. Sorting by Multiple Columns
SELECT * FROM Student ORDER BY

Order of execution
•	Where-> group by-> having-> order by
 
-- 4. Students with Grades Between 80 and 90, Grouped by Email Domain, Having More Than 1 Student per Domain, Ordered by Student Count
SELECT SUBSTRING_INDEX(email, '@', -1) AS email_domain, COUNT(*) AS student_count
FROM Student
WHERE grade BETWEEN 80 AND 90
GROUP BY email_domain
HAVING COUNT(*) > 1
ORDER BY student_count DESC;
 
-- 5. Students with Grades Above 85, Grouped by Grade, Having an Average Grade Above 85, Ordered by Grade in Ascending Order
SELECT grade, AVG(grade) AS average_grade, COUNT(*) AS student_count
FROM Student
WHERE grade > 85
GROUP BY grade
HAVING AVG(grade) > 85
ORDER BY grade ASC;
 
-- 7. Students with Enrollment Date in 2024, Grouped by Enrollment Date, Having an Average Grade Above 85, Ordered by Enrollment Date
SELECT enrollment_date, AVG(grade) AS average_grade
FROM Student
WHERE YEAR(enrollment_date) = 2024
GROUP BY enrollment_date
HAVING AVG(grade) > 85
ORDER BY enrollment_date;

Execution Order:
WHERE → GROUP BY → HAVING → ORDER BY

These questions are ideal for teaching the SQL execution order:
WHERE → GROUP BY → HAVING → ORDER BY
They clearly demonstrate:
WHERE filters rows before grouping.
GROUP BY creates groups.
HAVING filters the groups.
ORDER BY sorts the final result.
